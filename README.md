# koinagifan

こいなぎさん（X: @naginyan135）が紹介した詰将棋の投稿リンクを整理し、学習の出来具合と復習を記録する非公式サイトです。

## 機能

- 収録2,848問 / 24テーマ / 2,764投稿（2026-10-23の収集データ。全投稿の網羅は未達）
- 未挑戦・練習中・解けた・マスターを問題ごとに記録
- 全体とテーマ別のマスター率、1日の目標
- 復習日（練習中1日後 / 解けた3日後 / マスター14日後、手動変更可能）
- 番号・タイトル検索、テーマ・達成度の絞り込み、並び替え、ランダム選択
- お気に入り、自分用の回答とメモ、学習履歴
- JSONバックアップと日時によるマージ取り込み
- モバイル対応、キーボード操作、外部依存なし

判定は自己評価です。自動採点は行いません。同じ投稿に複数の収録図がある場合も、既存の固定問題番号を維持しています。投稿内の図の対応は元投稿を確認してください。リンクの有効性や投稿の許諾状況を本プロジェクトで保証するものではありません。

## データの扱い

`dist/catalog.json` は番号・短い題名・テーマ・元投稿URL・投稿日・同一投稿の収録件数のみです。元画像、投稿本文、棋譜、解答は配布していません。投稿日はXの投稿IDから日本時間で算出しています。紹介者が作品の作者とは限りません。

学習データは訪問者のブラウザの localStorage（`koinagifan.progress.v1`）に保存されます。サーバー送信、分析ツール、アカウント登録はありません。ブラウザのデータ削除で失われるので、JSONバックアップを推奨します。バックアップには個人のメモ・回答が含まれます。リポジトリには入れないでください。

## 開発

Node.js 22以降。外部パッケージのインストール不要。

```sh
npm run build
python3 -m http.server 8000 --directory dist
```

`dist/` が完成済みの静的サイトです。相対パスを使用するため、GitHub Pagesのサブパスにも独自ドメインにも対応します。

## 公開・ドメイン移行

GitHubが正本です。`main` へのpushで検証し、GitHub ActionsからPagesへ `dist/` を公開します。GitHub Settings → Pages → Source は **GitHub Actions** に設定します。

将来の候補ドメイン：`koinagifan.kdking-tools.com`。現時点でDNS変更・独自ドメイン設定はしません。

GitHub Pagesで移行する場合は、PagesのCustom domainに上記ホストを登録し、DNSで `koinagifan` のCNAMEを `kodaka-yutaro.github.io` に設定します。証明書が利用可能になったらHTTPSを有効にします。別の静的ホストでは `dist/` を公開ディレクトリに指定してください。

localStorageはオリジンごとに独立しています。**移行前に旧URLでバックアップをダウンロードし、移行後に新URLで取り込み**してください。問題IDは変えないため、達成度・メモ・履歴を引き継げます。端末を変えるときも同じ手順です。

収録を修正する場合は既存IDを変更・使い回ししないでください。削除・修正依頼はIssuesで受け付けます。
